## 4. Обычный вопрос по корпусу

Вопрос:

> Как концентрация кислорода влияет на скорость горения?

Точный сгенерированный ответ — HTTP 200 за 21,808 секунды:

> Скорость горения зависит от режима:
> - **Теплово-проводящий тонкий слой** → обратно пропорциональна плотности поверхности топлива ([doc_id, стр. 91]).
> - **Теплово-проводящий толстый слой** → не зависит от плотности ([doc_id, стр. 91]).
>
> При **критическом ограничении кислородом** → искривлённая фронтальная поверхность (увеличенная площадь) способствует горению в атмосфере с 21% O₂ ([doc_id, стр. 97]). Для CO₂-разбавленной атмосферы в микрогравитации горение стабильно при 21% O₂, тогда как в нормальной гравитации — нет ([doc_id, стр. 97]).

Найденные источники:

1. `NTRS-20000030678-Cooperative-Research-Projects-in-the-Microgra`, страница 91
2. `NTRS-20000030678-Cooperative-Research-Projects-in-the-Microgra`, страница 97
3. `NTRS-20210011385-Burning-and-Suppression-of-Solids-II-BASS-II-`, страница 138

Оценка: **ПРЕДУПРЕЖДЕНИЕ**. Утверждения прослеживаются до страниц 91 и 97,
неподтверждённых чисел модель не добавила. Однако в ответ не попали самые
прямые выводы из найденных фрагментов: при росте концентрации кислорода
уменьшается задержка воспламенения и повышается температура пламени. Кроме
того, вместо настоящих ID документов модель вывела буквальные шаблоны
`[doc_id, стр. N]`.

## Замеченная эксплуатационная проблема

При отключённом прогреве во время запуска инициализация сервиса эмбеддингов
выполняет несколько запросов метаданных к Hugging Face, хотя веса модели уже
есть локально. Из-за этого холодный запрос health занял 11,465 секунды, а при
полностью автономном запуске возможны повторные попытки соединения. На время
прогретых запросов `/query` в этом прогоне это не повлияло.
